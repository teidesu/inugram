## New
- [Behavior › Extra text actions](tg://settings/inu/selection-process-text): "Web search" and actions from other apps (e.g. "Ask Claude") in the message text selection menu
- "Show hidden messages" in the chat menu, to see messages from blocked/hidden users until the chat is closed
- Drawer: "New channel" item

## Improved
- Link cleaning: clean up Ozon redirects, `?a` in Twitter links
- Sending messages with links that are still resolving redirects no longer blocks the app
- Video editing (mute, quality, crop) works for AV1 and other formats supported by the device decoders
- Original video quality sends unedited videos unchanged regardless of codec or container
- Icon packs: sharper SVG icon rendering, support for animated icon replacements
- Extra bottom padding under stickers is always removed
- "Disable glass glare" covers the new QR and lockscreen buttons
- Drawer closes on back instead of exiting the app

## Fixed
- MP4 documents resent as videos
- Own channel posts showing a text signature with author profiles enabled
- Reactions with equal counts swapping places
- Unread reactions counter stuck after the server reports a reaction as read
- Replies to inaccessible chats showing truncated text
- Disappearing HD photos in secret chats showing only the thumbnail
- Height animation when opening reply/forward options
- Rotating in the avatar editor
- Emoji panel crash when a touch is cancelled during a tab drag
- Drawer "New message" and "New group" items swapped
- Classic UI: call bar in dialogs, player panel offsets in shared media, folder strip ripple clipped in the forward picker
- Round messages: legacy Camera2 flag kept after switching to the new recorder
- AdGuard filter lists with plain wildcard rules
- Memory leaks in the emoji panel

## Plugins
- Message filtering/rewriting api
- Custom text entities
- Translation providers are selectable by long-tapping "Translate" in the message menu
- `.inu.js` files can be installed by tapping them in global search and shared media
- `tg://inurepo` deeplink to add a plugins repo
- Regexes are matched with QuickJS libregexp everywhere
