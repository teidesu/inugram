## New & Improved
- Edit text messages that are not sent yet
- Round recorder: 640p output and up to 4 Mbps bitrate in Camera2 recorder settings
- Cross-account chats: chat preview on long-press, pinning per folder
- Reply jump stack now changes icon when there are replire to jump to
- Zalgo capped at 2 combining marks per character, like tdesktop
- Registration date estimate uses a [newer ID dataset](https://github.com/sepiol026-wq/telegram-id-age-research)
- Drawer and menu visual tweaks

- Unread reactions counter sometimes going stale (yes, still)
- Album caption quotes clipped in compact mode, with dead tap zones and no press animation
- Non-square Lottie animations stretched (QR login, folders, 2FA, calls, voice mic)
- Chat list not scrolling when dragging right after a long-tap select
